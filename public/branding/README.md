OFFICIAL LOGO REPLACEMENT
=========================
An exact, trustworthy original logo for the Moore facility was not found.
A temporary custom text/shape wordmark is included. It is NOT the official logo.

To install the actual organization logo once provided with permission:
1. Place the approved image at public/branding/official-logo.png
2. Open src/lib/site.json and set "logoUrl": "/branding/official-logo.png"
3. Run npm run generate (or npm run dev / npm run build).
4. If you want to use it in the social sharing card too, replace public/og-card.png.
Do not substitute logos from similarly named unrelated organizations.
